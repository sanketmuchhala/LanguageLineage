How AI frameworks run your code

Each explainer below traces one AI framework from the line of code you write to the chip that runs it. Pick a mode and a device, and the diagram shows which stages your code passes through. Every stage and every arrow quotes the official documentation or source code that supports it.

Trace JAX from Python to the device: op-by-op dispatch vs jax.jit, through jaxpr, StableHLO, the XLA compiler, LLVM or Triton, and the PJRT runtime, with sources.

  • Mode: Without jit, jax.jit
  • Device: CPU, NVIDIA GPU, TPU

Follow a local LLM through llama.cpp: GGUF file, ggml compute graph, and the CPU, CUDA or Metal backend, with the language each kernel is written in and sources.

How these pages are built

Each explainer is one versioned JSON file (how-jax-runs.json, how-llama-cpp-runs.json, how-mlx-runs.json, how-pytorch-runs.json, how-vllm-runs.json) under the same CC BY 4.0 license as the dataset. They are kept apart from the language lineage graph on purpose: "lowers to" and "dispatches to" describe how code executes, not what a tool is written in. Closed systems are not guessed at; where the public documentation stops, the diagram stops too. Found a mistake? Open an issue with the better source.
