About BCPL

BCPL is a multi-paradigm programming language. It is an untyped language that compiles ahead of time to native machine code. It supports imperative and procedural programming.

BCPL first appeared in 1967 and was designed by Martin Richards.

BCPL in the language family tree

BCPL drew on ideas from CPL and went on to influence B, Go, and C.
