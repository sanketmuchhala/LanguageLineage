About Hare

Hare is a programming language. It is a statically typed language that compiles ahead of time to native machine code. It supports systems, imperative, and procedural programming.

Hare first appeared in 2022. Development is led by Drew DeVault. Hare is now used mainly in specialized niches and by dedicated communities.
