What Delphi is used for

Delphi (Object Pascal) is a rapid application development tool for native Windows, and now cross-platform, desktop software, known for fast compilation and visual form design.

Notable software: the original Skype client and many long-lived business and point-of-sale applications.

About Delphi

Delphi is an Integrated Development Environment for specific dialect of Object Pascal language. It is a statically typed language. It supports imperative and object-oriented programming.

Delphi first appeared in 1995. Development is led by Embarcadero Technologies.
