What is Carbon written in?

Compiler implementation

The Carbon compiler, written in C++, translates Carbon source code into an executable or intermediate format. The choice of implementation language affects the compiler's portability, build-time dependencies, and the path toward Carbon eventually becoming self-hosting.

Many language compilers are written in C or C++ for maximum portability and performance. When a compiler is written in a higher-level language, it can leverage that language's abstractions for clearer compiler code, at the cost of a longer bootstrap dependency chain.
