What is PureScript written in?

The PureScript compiler is written in Haskell.

PureScript is a strongly typed language that compiles to JavaScript, first released in 2013.

Compiler implementation

The PureScript compiler, written in Haskell, translates PureScript source code into an executable or intermediate format. The choice of implementation language affects the compiler's portability, build-time dependencies, and the path toward PureScript eventually becoming self-hosting.

Many language compilers are written in C or C++ for maximum portability and performance. When a compiler is written in a higher-level language, it can leverage that language's abstractions for clearer compiler code, at the cost of a longer bootstrap dependency chain.
