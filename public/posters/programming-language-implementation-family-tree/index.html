Programming Language Implementation Family Tree

What are programming languages written in? Mostly C: 50 of the languages and tools in the dataset have a current compiler or runtime written in C, while 28 are self-hosted and compile themselves. This poster groups 174 languages and tools by the language their implementation is written in today, from 226 cited relationships.

How the poster is made

Each card is an implementation language. Under it are the languages and tools whose compiler or runtime is written in that language today, using the dataset's compiler written in, runtime written in, rewritten in edges that have no end year. Historical implementations are left out, so Go appears as self-hosted rather than under C, which wrote its compiler until 2015; for those changes over time see how compilers bootstrap. Influence and transpilation edges are not drawn.

A language can appear on several cards when the dataset records parts of its implementation in different languages: Julia appears under C, C++, Self-hosted, and LLVM. Cards with fewer than 3 entries are merged into "Everything else". Every edge links to its source on the relationship pages and in the downloadable dataset.
